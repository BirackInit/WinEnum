# ProjetWinAudit - Active Directory

> [!Note]
> ## 🚀 Fonctionnalités
Ce script PowerShell permet d'afficher diverses informations sur le système d'exploitation, les utilisateurs, les services en cours, et bien plus encore :
- Affiche des informations sur le système d'exploitation (nom, version, architecture, etc.).
- Liste les fichiers partagés sur les systèmes.
- Affiche les utilisateurs du système.
- Affiche les services en cours d'exécution.
- Liste les journaux d'événements récents.
- Identifie les services malconfigurés (non démarrés automatiquement).

## 📖 Utilisation
1. Ouvrez une console PowerShell avec les privilèges d'administrateur.
2. Exécutez le script en utilisant la commande suivante :
   ```powershell
   .\WinAudit.ps1

Vous serez invité à choisir l'option souhaitée parmi celles proposées :
* Afficher des informations sur le système d'exploitation.
* Afficher les fichiers partagés.
* Afficher les utilisateurs.
* Afficher les services en cours d'exécution.
* Afficher les journaux d'événements récents.
* Afficher les services malconfigurés.

## 📋 Exigences

Système d'exploitation : Windows 10 ou version supérieure.  
Privilèges : Le script doit être exécuté depuis un compte administrateur de domaine.   
PowerShell : Version 5.1 ou ultérieure.


> [!Caution]
> ## ⚠️ Remarque

Avant d'exécuter ce script, assurez-vous d'avoir les droits d'administrateur nécessaires. Ce script ne doit être exécuté que dans un environnement sécurisé ou avec l'autorisation des propriétaires des systèmes.


> [!Important]
> ## ⚠️ Disclaimer

Cet outil doit être utilisé dans un cadre légal et éthique, exclusivement pour :

* Des tests d'intrusion autorisés avec l'accord explicite des propriétaires des systèmes concernés.
* Des analyses de sécurité dans le cadre de missions légales avec consentement.
* Un usage personnel en laboratoire pour des tests sur des environnements contrôlés.
